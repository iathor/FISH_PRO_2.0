КАТАЛОГ ЗАГРУЗКИ И ОБНОВЛЕНИЙ ANDROID APK («КЛЁВ ПРО 2.0»)
=========================================================

Этот каталог (/apk/) в основном репозитории сайта (https://klevpro.ru/apk/) используется для:
1. Скачивания установочного файла .APK пользователями Android-смартфонов напрямую с сайта klevpro.ru.
2. Быстрой проверки выхода новой версии приложения внутри установленного Android APK (через лёгкий файл apk-version.json).

КАК ВЫПУСТИТЬ НОВУЮ ВЕРСИЮ APK:
1. Соберите подписанный APK через GitHub Actions (или в Android Studio) и положите файл в эту папку `/apk/` под именем:
   - `klev-pro-v2.2.0.apk` (или укажите новое имя файла в поле `"apkUrl"` внутри `apk/apk-version.json`).
2. В файле `apk/apk-version.json` обновите:
   - `"version"`: например `"2.2.1"`
   - `"versionCode"`: например `22001`
   - `"apkUrl"`: прямая ссылка на новый файл (например `"https://klevpro.ru/apk/klev-pro-v2.2.1.apk"`)
   - `"changes"`: список изменений простыми словами для пользователей (без технических подробностей кода).
