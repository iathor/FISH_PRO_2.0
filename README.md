# 🎣 Клёв ПРО 2.0 (v2.0.0) — Прогноз клёва и Атлас Ихтиофауны РФ

**Клёв ПРО 2.0** — прогрессивное веб-приложение (PWA) для рыболовов России: многофакторный расчёт биологической активности рыб по 11 рыбохозяйственным бассейнам РФ, интерактивная карта водоёмов и глубин, годовой календарь биоритмов и нереста, а также персональный офлайн-журнал уловов.

## ✨ Ключевые возможности версии 2.0.0

* **Атлас ихтиофауны по 11 бассейнам РФ:** фильтрация рыб по текущему бассейну и биотопу водоёма (с исключением равнинных видов из горных рек Черноморского побережья и автоматическим открытием морских биотопов при выборе прибрежных регионов — Каспий, Чёрное, Азовское, Балтийское, Баренцево, Белое и дальневосточные моря).
* **Профильные снасти и сезонные наживки:** автоматический подбор совместимых снастей и оснасток с учётом мирного или хищного типа рыбы, температуры воды и ледовой обстановки.
* **Прогноз на 10 дней + 2 архивных дня («Позавчера», «Вчера»):** декомпозиция факторов клёва по часам (`00:00–23:00`), учёт тепловой инерции воды, барометрических скачков («барометрический удар»), штормового ветра и ледового режима.
* **Плавная миниатюризация ленты рыб:** при вертикальном скролле карточки рыб плавно трансформируются в компактную закреплённую панель под шапкой без пустых отступов, позволяя переключать вид рыбы в любой вкладке.
* **Интерактивная карта (Leaflet) + офлайн-база водоёмов РФ:** 4 картографических слоя в одну строку (`Топо`, `Спутник`, `Схема`, `OSM`), автоматический поиск ближайших рек, озёр и водохранилищ через встроенный справочник гидрографии РФ и Overpass API.
* **Годовой биологический календарь:** одиночный режим с выгрузкой нерестового периода в `.ics` и режим сравнения 2–3 видов с расчётом месяцев пересечения активного жора (`🔥 Общий жор`).
* **Персональный журнал уловов (IndexedDB + LocalStorage):** запись уловов за сегодня или по архивной погоде за прошлые дни по цепочке *Рыба → Снасть → Наживка → Водоём*, прикрепление фото и экспорт в `.json`.
* **Полная автономность (Offline-First PWA):** Service Worker (`sw.js`) кэширует все модули интерфейса и просмотренные тайлы карты для работы на водоёме без связи.

## 🚀 Размещение на GitHub и запуск GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `klev-pro-v2`).
2. Распакуйте архив и загрузите файлы в корень репозитория:
   ```bash
   git init
   git add .
   git commit -m "Release Клёв ПРО v2.0.0"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings → Pages**:
   * В разделе **Build and deployment → Source** выберите `Deploy from a branch`.
   * Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через 1 минуту приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/` с поддержкой установки как PWA на смартфон и офлайн-работы через Service Worker.

## 💻 Локальный запуск

* **Через локальный сервер (рекомендуется для работы ES6-модулей и Service Worker):**
  ```bash
  python3 -m http.server 8080
  # Откройте http://localhost:8080 в браузере
  ```
* **Прямой запуск без сервера (однофайловая версия):**
  Откройте файл `standalone/klev-pro-v2.html` в любом браузере на телефоне или ПК.
