# 🎣 Клёв ПРО 2.0 • Прогноз клёва и Атлас Ихтиофауны РФ

Научно-прикладное веб-приложение (PWA) для расчёта биологической активности пресноводных и морских видов рыб по **11 рыбохозяйственным бассейнам Российской Федерации** с офлайн-базой гидрографии РФ, батиметрическим профилем водоёмов, рабочей кнопкой установки PWA (`📲`), адаптивным справочником ихтиолога, архивом погоды и локальным журналом уловов (`IndexedDB`).

## 🏗 Модульная архитектура (Native ES6 Modules)

Проект полностью разбит на независимые изолированные модули (`<script type="module" src="js/app.js">`) — редактирование любого отдельного модуля не затрагивает остальные части приложения:

```text
├── index.html                              # Точка входа (модульная ES6-сборка)
├── manifest.json                           # Конфигурация PWA для установки на смартфон/ПК
├── icon.svg                                # Векторная иконка приложения («КЛЁВ PRO»)
├── sw.js                                   # Service Worker v2.0.0 (офлайн-кэш модулей и тайлов карт)
├── package.json                            # Метаданные проекта и скрипты локального запуска
├── .nojekyll                               # Отключение Jekyll-обработки для GitHub Pages
├── css/
│   ├── tokens.css                          # Цветовые токены тёмной и светлой тем, типографика
│   ├── base.css                            # Сброс стилей и базовая доступность
│   ├── components.css                      # Кнопки, чипы, карточки рыб, почасовая шкала, модалки
│   └── layout.css                          # Адаптивная сетка, закреплённая шапка, миниатюризация ленты рыб
└── js/
    ├── app.js                              # Инициализация приложения, синхронизация шапки и скролла
    ├── i18n/
    │   └── ru.js                           # Русскоязычные словари, статусы и памятки рыболова
    ├── core/
    │   ├── config.js                       # Константы, слои карт, сезонные наживки и совместимость снастей
    │   ├── events.js                       # Шина событий (Pub/Sub) для слабой связности модулей
    │   ├── format.js                       # Форматирование дат, температуры, давления и экспорт .ics
    │   ├── http.js                         # Таймауты, повторные попытки и цепочки фоллбэков (fallbackChain)
    │   ├── pwa.js                          # Установка PWA («📲 Ярлык на экран»), генерация иконки, модалка-инструкция
    │   ├── router.js                       # Hash-маршрутизатор разделов (#/dashboard, #/forecast и др.)
    │   ├── storage.js                      # Обёртка над IndexedDB (уловы, точки) и localStorage (кэш)
    │   └── store.js                        # Централизованное реактивное хранилище состояния (Store/Reducer)
    ├── data/
    │   ├── basins.js                       # 11 рыбохозяйственных бассейнов РФ и детектор морских побережий
    │   ├── waters.js                       # Профили биотопов (реки, озёра, вдхр, тёплые сбросы, море)
    │   ├── russia-waters.js                # Офлайн-база рек, озёр, водохранилищ, заливов и городов РФ
    │   └── species.js                      # База видов рыб РФ (биология, глубины, нерест, температурный оптимум)
    ├── ui/
    │   ├── components.js                   # Фабрики UI-компонентов, тосты и модальные окна
    │   └── svg.js                          # Кастомная SVG-графика рыб и 5-рыбовая шкала клёва
    └── modules/
        ├── weather/
        │   └── weather.module.js           # Метеоядро (Open-Meteo → AllOrigins → MET.no → офлайн), Луна и лёд
        ├── geo/
        │   └── geo.module.js               # Карта Leaflet, 2-этапный GPS, поиск водоёмов, рельеф дна и закладки
        ├── fish/
        │   └── fish.module.js              # Атлас рыб, фильтры, избранное, карточка вида и профиль рыболова
        ├── forecast/
        │   └── forecast.module.js          # Расчёт клёва, 3-дневная сводка, почасовой график, гид ихтиолога и архив
        ├── calendar/
        │   └── calendar.module.js          # Годовой биоритм, региональный сдвиг нереста и сравнение до 3 видов
        └── log/
            └── log.module.js               # Журнал уловов («Я поймал»), реактивная цепочка выбора и статистика
```

## 🚀 Размещение на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите содержимое архива в корень репозитория (включая папки `css/`, `js/` и файлы `index.html`, `manifest.json`, `sw.js`, `.nojekyll`).
3. Перейдите в **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch** → ветка `main` / папка `/ (root)` → **Save**.
4. Через 1 минуту приложение будет доступно по HTTPS-ссылке вида `https://<ваш-логин>.github.io/<имя-репозитория>/`, после чего на смартфонах и ПК заработает прямая установка через кнопку **📲 Ярлык на экран**.
